# Real-time multi-terrain assistance state classification and calibration for cable-driven suits using biomechanically scaled sEMG

Song-Bi Lee, Yongjun Kim, Gisu Heo, Changmok Oh, Suyeong Eom¹, Dong-Woo Lee*

Electronics and Telecommunications Research Institute (ETRI), Daejeon, Republic of Korea  
¹ Formerly at ETRI  
*Corresponding author: Dong-Woo Lee (hermes@etri.re.kr)

## Abstract

Closed-loop control of cable-driven wearable assist suits requires real-time discrimination of assistance states from sEMG that generalizes across terrains. We collected 10-channel sEMG (2,148 Hz) from 10 healthy adults (29,993 gait cycles) on level ground, slope and stairs, and segmented each cycle into eight phases. We extracted multi-domain features (F28 = 18 time–frequency–wavelet + 10 nonlinear) and applied fixed literature-derived muscle-architecture scaling (Φ\_B) to channel-level feature vectors prior to fusion, then classified NW/UE/PE using Random Forest. In LOSO evaluation on a balanced dataset (≤50 cycles per recording file, seed=42), same-terrain macro-F1 was 0.375–0.399 and cross-terrain macro-F1 was 0.171–0.394. Leakage-free 0-label terrain normalization using training-subject statistics improved the transfer-to-same-terrain ratio from 0.43–0.52 to 0.67–0.81. A leakage-safe unlabeled subject-window (first 4 cycles per recording file) further improved the weakest transfers (level→slope 0.273→0.301; level→stairs 0.269→0.290). On Apple M1, the lightweight deployment pathway (F18+RF) achieved 115 ms per-cycle end-to-end (p99 182 ms) and 1.36 ms inference-only per 28D feature vector.

## Main text

### Introduction

Wearable gait assistance systems such as cable-driven suits may require real-time discrimination of user assistance states for adaptive closed-loop control¹,²,¹⁶⁻²⁰. Surface electromyography (sEMG) can non-invasively measure muscle activity and has been used for gait mode identification, prosthetic control, and classification³,⁴,²¹⁻²⁵. Various time, frequency, and wavelet features have been proposed for EMG classification⁴,²⁶⁻³⁴,⁴²⁻⁴⁴, while nonlinear dynamics measures such as sample entropy, approximate entropy, permutation entropy, and fractal dimensions can capture signal complexity associated with gait variability⁵,⁹,¹²,¹³,¹⁴,³⁶⁻⁴¹. Because we fuse ten muscle channels into a single feature vector, we applied fixed muscle-architecture scaling (Φ\_B; derived from anatomical PCSA, fiber-type fraction and pennation angle) to weight channel features by force-generating capacity rather than raw magnitude⁶,¹⁰.

Here, we implemented the hierarchical multi-domain wavelet ensemble fusion (H‑MD‑WEF) pipeline, linking phase-aligned multi-domain feature fusion to both interpretable coordination metrics and a multi-terrain inference module (Fig. 1). The shared backbone performs preprocessing, HS/TO-based 8-phase segmentation, multi-domain feature extraction (F18: time, frequency, wavelet), and applies Φ\_B, then generates s10 (10D) via information-theoretic (entropy-based) intra- and inter-domain fusion. Nonlinear features (NL10; 10D) are computed separately only for segments ≥50 samples, and combined with F18 to form F28 = F18 + NL10 for classification. To avoid target-label dependence, the inference results reported here use a condition-agnostic fixed wavelet ensemble and do not use label-conditioned weights. Using this backbone, we evaluated five endpoints: (1) subject-independent multi-terrain LOSO classification with cross-terrain transfer, (2) deployment-realistic calibration (0-label, unlabeled subject-window, and small-label), (3) latency (inference-stage and end-to-end reported separately), (4) inter-muscle correlation network-based coordination metrics with threshold robustness, and (5) feature module ablation effects.

## Results

All results below were computed from the event- and phase-aligned feature tables (F18/F28) and fused latent states (s10) generated by the H‑MD‑WEF pipeline (Fig. 1). We report subject-independent cross-terrain classification (Fig. 2a; Source Data Fig.2), calibration strategies (Fig. 5a; Source Data Fig.5), latency (Fig. 4), and interpretable coordination metrics with ablation (Fig. 3).

### Study design and data

From 10 healthy men (age 25.3 ± 3.2 years), we collected 29,993 gait cycles across three terrains (level ground, 18° slope, stairs) and three assistance conditions (NW: not worn, UE: worn-inactive, PE: worn-active). Gait cycles were defined as heel strike to next heel strike (HS→next HS) on the same foot, and each cycle was segmented into Perry 8 phases via HS/TO events, yielding 239,944 cycle×phase samples (8 phases per cycle). Because NL10 is computed only for phase segments ≥50 samples, 19,973 of 239,944 cycle×phase samples (8.32%) were classified as NL10-invalid and excluded from F28 analyses (Supplementary Table S3). The distribution by terrain was 16,455 cycles for level ground, 6,412 for slope, and 7,126 for stairs (Table 1). Slope (18°) trials included both uphill and downhill segments (3,022 uphill; 3,390 downhill; 6,412 total). For classification input (F28, 28D), channel-specific features from 10 channels (bilateral GM/TA/RF/TFL/BF) were aggregated by arithmetic mean to form one vector per cycle×phase sample; for coordination analysis, channel-specific features were retained to compute 10×10 inter-muscle (channel) correlation matrices.

### Subject-independent cross-terrain classification

Subject-independent evaluation using Random Forest (RF) was performed via leave-one-subject-out (LOSO): for each fold, one subject was completely held out for testing while the remaining nine subjects provided training data. In cross-terrain transfer (3×3 transfer matrix; train on one terrain, test on one terrain), same-terrain diagonal performance was macro-F1 0.375–0.399, and cross-terrain off-diagonal performance ranged from 0.171 to 0.394 (Fig. 2a; Source Data Fig.2). By training terrain, the level model achieved 0.398/0.179/0.171 on level/slope/stairs; the slope model achieved 0.206/0.375/0.394; and the stairs model achieved 0.200/0.350/0.399. Macro-F1 was computed per held-out subject, then aggregated as the unweighted arithmetic mean across subjects (n = 10); 95% CIs were obtained via subject-level bootstrap (2,000 iterations). For these LOSO experiments, we evaluated on a balanced cycle×phase dataset constructed by randomly sampling up to 50 cycles per recording file (seed=42).

The off-diagonal/diagonal ratio, defined as each off-diagonal cell normalized by the diagonal of the same test-terrain column, was 0.43–0.99. The weakest transfers were level→slope/stairs (0.48, 0.43), and the strongest were slope↔stairs (0.99, 0.93). Cross-terrain degradation was class-dependent: in level→slope, UE maintained F1 = 0.503 while NW was 0.033 and PE was 0.001; in level→stairs, UE was 0.467 versus NW 0.040 and PE 0.005, showing a similar pattern.

### Deployment-realistic calibration

To address cross-terrain degradation, we evaluated two calibration strategies implementable in deployment scenarios.

For 0-label calibration, we applied terrain-specific z-score normalization using statistics computed only from training subjects (train_only_by_terrain), assuming the test terrain label is known at deployment to select the corresponding terrain statistics. Each sample was transformed using the statistics corresponding to its terrain label, and no held-out subject data were used to compute μ/σ (leakage prevention). This calibration improved the weakest cross-terrain cells (level→slope 0.179→0.273; level→stairs 0.171→0.269). Additionally, the mean macro-F1 across 6 off-diagonal cells increased from 0.250 to 0.309, and the diagonal-normalized ratio range improved from 0.43–0.99 to 0.67–0.91. However, the strong slope↔stairs transfers decreased modestly (0.394→0.334; 0.350→0.340) (Fig. 2c; Source Data Fig.2).

To explore leakage-safe unlabeled subject adaptation (“personalization”), we estimated per-(subject, terrain) normalization statistics from an initial calibration window on the held-out subject (first 4 gait cycles per recording file; excluded from evaluation). This improved the weakest transfers beyond train-only 0-label calibration (level→slope 0.273→0.301; level→stairs 0.269→0.290), with modest mixed effects on other transfers; mean off-diagonal macro-F1 increased from 0.309 to 0.315 (Extended Data Fig. 7; Source Data Extended Data Fig. 7).

For small-label calibration, in leave-one-terrain-out (train on 2 terrains, test on 1 terrain) LOSO, after applying 0-label subject×terrain z-score (subject_by_terrain) to input features, we post-hoc trained a multinomial logistic regression (solver=lbfgs, L2, C=1.0, max_iter=1000) on log(RF probabilities) from the held-out subject×test terrain. The label budget was 10/30/90 total labeled cycle×phase samples from the held-out subject×test terrain, selected via stratified sampling prioritizing equal class allocation (replacement allowed for insufficient classes), and selected label samples were excluded from evaluation. Across 30 repeated random samplings (fixed seed=42), baseline macro-F1 of 0.312–0.387 at 0 labels improved to 0.400–0.532 at 30 labels, with between-repetition SD decreasing from 0.019–0.021 (10 labels) to 0.006–0.010 (90 labels) (Fig. 5a; Source Data Fig.5). Since each cycle yields 8 phase samples, 10/30/90 labels correspond to a minimum of 2/4/12 gait cycles (up to 10/30/90 cycles).

### End-to-end latency

We measured latency for the complete processing pipeline on Apple M1 hardware across 5 gait cycles per terrain (N = 15 total across three terrains). Percentiles (p95/p99) were computed as empirical quantiles over the distribution of N = 15 per-cycle measurements.

Full F28 pathway (including NL10 nonlinear features): mean end-to-end latency was 2,697 ms (p95 5,815 ms, p99 5,845 ms), dominated by NL10 computation (2,559 ms of 2,591 ms feature extraction time). This pathway is not suitable for real-time control.

F18 deployment pathway (excluding NL10, including RF inference): mean end-to-end latency was 115 ms (p95 147 ms, p99 182 ms). Per-cycle latency represents the total time to compute muscle-mean 28D features for all 8 phases within one gait cycle (HS→HS) and perform RF inference for each phase vector (up to 8). Mean stage times were event detection 8 ms (measured once per file then divided by cycle count), preprocessing 28 ms, F18 feature extraction 26 ms, and RF inference 52 ms; by terrain, mean latency was level 125 ms, slope 105 ms, stairs 116 ms.

Inference-only latency (single pre-computed feature vector): mean 1.36 ms (p99 2.36 ms), utilizing 13.6% of a 100 Hz control budget (10 ms).

Real-time in this study refers to inference-stage latency. The mean end-to-end 115 ms for the F18+RF pathway corresponds to throughput of approximately 8.7 Hz (≈9 Hz; ≈1/0.115 s); end-to-end closed-loop control at 100 Hz (10 ms budget) would require optimization of feature computation and implementation.

### Coordination network analysis

Inter-muscle (channel) coordination, analogous to the modular structure observed in muscle synergy studies⁴⁵⁻⁵⁰, was quantified by computing Pearson r between muscle-specific feature trajectories from 10 channels (bilateral GM/TA/RF/TFL/BF) to form 10×10 correlation matrices, then calculating the proportion of 45 off-diagonal muscle pairs with |r| ≥ 0.6 (network density) (Fig. 3a). Values were computed per subject (run_id), then summarized as mean ± SD; on level ground, NW/UE was 1.000 ± 0.000 and PE was 0.904 ± 0.302, approaching the upper bound, while slope (uphill/downhill) and stairs showed lower densities (0.129–0.198), indicating sparser connectivity.

To assess metric robustness, we computed normalized network density (edges_auc_norm) across four threshold ranges (0.30–0.90, 0.40–0.80, 0.50–0.90, 0.40–0.90). Condition ordering was fully consistent across ranges: slope NW > UE > PE; stairs PE > UE > NW (Extended Data Table 1). Level ground showed saturation effects at narrow ranges due to high baseline connectivity. These results indicate that coordination conclusions are robust to threshold selection within reasonable ranges.

### Feature module ablation

Removal of individual feature modules (ablation) was evaluated for each terrain×condition cell via two-sided paired t-tests on subject-level mean |r| (arithmetic mean of 45 muscle-pair Pearson |r| values) (Fig. 3b). For ablation analysis, slope was subdivided into downhill and uphill, yielding 4 terrains × 3 conditions = 12 cells (level, slope downhill, slope uphill, stairs). q-values used Benjamini–Hochberg correction across all comparisons (3 modules × 12 cells × 2 metrics [mean |r|, |r|>thr edge count] = 72), with q < 0.05 applied per cell. Wavelet feature (WEF) removal produced significant changes (q < 0.05) in 9 of 12 cells with mean |Δ(mean |r|)| = 0.211. NL10 removal was significant in only 2 cells (mean |Δ(mean |r|)| = 0.024), and biomechanical scaling (Φ\_B) removal in 3 cells (mean |Δ(mean |r|)| = 0.007). WEF ablation results reflect impact on coordination metrics (mean |r|); domain permutation importance below evaluates impact on classification performance (macro-F1).

Domain-level permutation importance analysis (LOSO, same-terrain) confirmed that NL10 features contributed the largest macro-F1 drop when permuted (0.065–0.072 across terrains, 95% CI excluding zero; subject bootstrap). Time, Frequency, and Wavelet domains showed smaller effects, often with CIs including zero (Extended Data Fig. 1).

### Event detection robustness

EMG-based HS/TO detection used the bandpass+notch-filtered rectified signal smoothed by a Gaussian (σ) to create an envelope, with TA envelope peaks as HS and GM envelope peaks as TO (envelope normalized by median/MAD, then find_peaks with minimum interval). TO was set as the GM peak closest to 62% of cycle duration after HS (or 62% if no GM peak); |Δt| was defined as the event timing difference relative to baseline parameters (σ=100 ms, min_interval=0.5 s). For parameter sensitivity, cycles were matched to baseline by nearest HS, restricted to "stable cycles" with variant/baseline cycle length ratio 0.8–1.2, and summarized; HS showed p95 |Δt| < 80 ms across all parameter combinations (Extended Data Table 2). Additionally, to simulate ±10/±20/±40 ms event errors, we shifted existing segment indices (phase_start/end) uniformly and recomputed F18 features (NL10 excluded) for classification sensitivity; at ±20 ms, macro-F1 changes were 0.007–0.022 (diagonal) and 0.003–0.018 (off-diagonal) (Supplementary Fig. 6).

## Discussion

This study presents a subject-independent evaluation of EMG-based assistance condition classification across multiple terrains and provides benchmarks—within this study setting—quantifying calibration requirements and computational feasibility.

The gap between subject-independent LOSO macro-F1 (same-terrain 0.375–0.399; Fig. 2a) and within-subject 5-fold stratified cross-validation macro-F1 (0.9997 ± 0.0003; Supplementary Table 6; not subject-independent) shows that high performance is achievable when sharing subject/recording context, but subject-independent generalization is limited. The 5-fold CV in Supplementary Table 6 was performed at the gait-cycle level (1 sample = 1 gait cycle), but since training and evaluation folds share subjects, this should be interpreted as an upper bound rather than deployment performance. The distribution of subject-level macro-F1 from 0.155 to 0.572 in LOSO (Supplementary Table 1) suggests that inter-individual EMG characteristic differences may be a major contributor to reduced generalization.

Importantly, 0-label calibration using only training-subject statistics (without held-out subject labels) improved the weakest cross-terrain transfer ratio from 0.43–0.52 to 0.67–0.81. However, 0-label calibration applies terrain-specific statistics, so it requires terrain identification at deployment (or assumes known terrain labels) to apply terrain-specific normalization.

Small-label calibration using 30 total label samples (stratified across conditions) provided stable improvement with low sampling variability (SD 0.008–0.010; Fig. 5a), whereas 10 samples showed higher variability (SD 0.019–0.021). Since each cycle yields 8 phase samples, 30 cycle×phase label samples correspond to approximately 4 gait cycles (30/8≈3.75) of labeled data. In this experimental setting, 30 labels appeared to be the minimum budget where both performance improvement and variability reduction were simultaneously observed.

End-to-end latency analysis clarifies the scope of "real-time" claims. Inference-only latency (mean 1.36 ms) is well within the 100 Hz control budget, but the full pipeline including feature extraction requires mean 115 ms for the F18+RF pathway—corresponding to approximately 9 Hz feedback in the current implementation. Latency values are distribution-based measurements from 5 gait cycles per terrain (N = 15 total), so additional measurements under more diverse conditions are needed. Higher-frequency closed-loop control may require design choices such as computing NL10 offline/at lower frequency or optimizing F18 computation and implementation.

Coordination metrics suggested terrain-dependent coupling structures: level ground showed density approaching the upper bound with potential saturation, while slope/stairs showed lower densities indicating sparser, selective coupling. The consistent condition ordering within each terrain across multiple threshold ranges supports the robustness of coordination metric interpretation.

Several limitations should be noted. First, the sample size of 10 subjects limits generalizability, and the healthy adult population may not represent clinical populations. Second, EMG-based event detection was not validated against external sensors (IMU, force plates); however, sensitivity analysis showed that ±20 ms timing shifts did not substantially alter conclusions. Third, LOSO macro-F1 of 0.375–0.399 (same-terrain; Fig. 2a) indicates limited subject-to-subject generalization. Fourth, 0-label calibration requires terrain identification at deployment (or assumes known terrain labels) to apply terrain-specific statistics. Fifth, the unlabeled subject-window adaptation assumes an initial calibration window and showed mixed effects across transfers. Sixth, latency was evaluated on 5 cycles per terrain (N = 15), so additional measurements under more diverse conditions are needed. Seventh, closed-loop control was not implemented; latency results establish computational feasibility but not control performance.

In conclusion, this study quantitatively presents subject-independent performance, calibration effects, latency, and coordination metrics for EMG-based assistance classification. Within the scope of this data/setting/pipeline, these results clarify calibration and optimization requirements for deployment.

## Online Methods

### Participants

Ten healthy men (age 25.3 ± 3.2 years; height 168.4 ± 8.7 cm; weight 64.2 ± 11.3 kg) participated. The study was approved by the institutional review board (IRB) of the authors' institution, and written informed consent was obtained from all participants.

### Protocol

Data were collected under three assistance conditions (NW: not worn, UE: worn-inactive, PE: worn-active) and three terrains. Level ground was performed on a treadmill at 0.83 m/s. Stairs were performed on an Egojin Highclimb stepmill machine (step height 21 cm) at 0.54 m/s. Slope (18°) was performed at self-selected speed on a 25 m walkway (50 m round trip; trial-average speed 0.227 ± 0.016 m/s). Mean recording durations were level 299 ± 23 s, slope 221 ± 17 s, stairs 180 ± 6 s. The round trip on slope included two segments in opposite directions on the same incline (18°), analyzed as uphill/downhill where reported.

### EMG acquisition

Ten-channel surface EMG was collected bilaterally from gastrocnemius medialis (GM), tibialis anterior (TA), rectus femoris (RF), tensor fasciae latae (TFL), and biceps femoris (BF) using a Delsys Trigno surface EMG system (hereafter, Trigno) at 2,148 Hz, following SENIAM electrode-placement guidelines⁷.

### Preprocessing

Sequential preprocessing: per-channel outlier clipping to 0.1–99.9 percentiles computed from nonzero samples within each recording (when ≥100 nonzero samples; zeros excluded from percentile calculation but retained in signal), 4th-order Butterworth band-pass (20–450 Hz), 60 Hz notch filter (Q = 30), rectification, and Gaussian envelope smoothing (σ = 100 ms).

### Gait segmentation

Heel strike (HS) was detected as TA envelope peaks; toe off (TO) as GM envelope peaks, using scipy.signal.find_peaks with minimum distance 0.5 s. For robust peak detection, the envelope was normalized by median/MAD, then peaks were searched with progressively relaxed thresholds: (height, prominence) = (0.5, 0.3) → (0.3, 0.2) → (0.1, 0.1) → (0.05, 0.05) → (None, 0.02), returning when ≥5 peaks were detected; as a last resort, peaks were detected using only the minimum distance constraint (if <2 HS peaks on one side, that side was excluded). For each cycle defined by consecutive HS peaks (HS→next HS), TO was selected as the GM peak closest to 62% of cycle duration after HS; if no GM peak occurred between HS and next HS, TO was estimated at 62% of cycle duration. Gait cycles were divided into 8 phases according to Perry's model⁸: IC (0–2%), LR (2–12%), MSt (12–31%), TSt (31–50%), PSw (50–62%), ISw (62–75%), MSw (75–87%), TSw (87–100%). Phase boundaries (%) were mapped to sample indices within each HS→next HS window (no time resampling), and these indices were used to segment phase windows. Cycles with HS→next HS length <50 samples were excluded.

### Feature extraction

F18 (18D) comprised time domain (6), frequency domain (5), and wavelet domain (7). Event detection used the envelope signal; F18 feature computation used the band-pass signal (bp) and its envelope (env): RMS/MAV/variance were computed on env; waveform length (WL), ZCR, and SSC were computed on bp (sign-change based, no additional ε-threshold). Frequency features were computed from bp using Welch PSD (scipy.signal.welch; nperseg=min(L,1024); other parameters at SciPy defaults) restricted to 20–450 Hz; relative band powers were defined as \(\int_{\mathrm{band}}P(f)\,df / \int_{20}^{450}P(f)\,df\). To avoid target-label dependence, wavelet features used a condition-agnostic fixed 3-wavelet ensemble (level=5): {db5, sym6, coif3} with fixed weights {0.5, 0.3, 0.2}. Weighted energies/entropies were concatenated, and high/low ratio was computed from the wavelet with the largest fixed weight. For segments too short for discrete wavelet decomposition (pywt.dwt_max_level < 1), wavelet summaries returned zeros (no wavelet decomposition available). NL10 (10D) comprised SampEn (m=2, r=0.2; z-scored signal), ApEn (m=2, r=0.2), permutation entropy (order=3, delay=1, normalized), Higuchi FD (kmax=min(10, N/4)), Katz FD, Hurst exponent (max_lag=min(50, N/4)), RQA metrics (m=2, τ=1, threshold=0.1×max distance; DET lmin=2; LAM vmin=2), and maximum Lyapunov exponent (Rosenstein; m=2, τ=1). NL10 was computed only for segments ≥50 samples (≈23 ms at 2,148 Hz); shorter segments were assigned NaN, and cycle×phase samples containing any NaN were excluded from F28 (F18+NL10) classification analyses (Supplementary Table S3).

### Biomechanical scaling

Scaling weights were calculated as \(w = w_\mathrm{PCSA}\,w_\mathrm{FT}\,w_\mathrm{pen}\), where \(w_\mathrm{PCSA}=1/\mathrm{PCSA}\), \(w_\mathrm{FT}=1+0.6(\mathrm{FT}-0.5)\) (FT: fast-fiber fraction), and \(w_\mathrm{pen}=1-\theta/90^\circ\) (θ: pennation angle). The resulting diagonal matrix Φ\_B was normalized to mean 1.0 across muscles and applied as a muscle-specific scalar multiplier to all features without per-subject individualization. Muscle parameters (PCSA, FT, θ) were taken from anatomical literature¹⁰,¹⁵ as fixed muscle-specific constants (left/right identical): GM (PCSA 15.6 cm², FT 0.51, θ 17°, w 0.473), TA (6.5, 0.27, 9.6, 1.072), RF (12.9, 0.39, 13.5, 0.557), TFL (4.2, 0.45, 8.0, 1.904), BF (8.7, 0.67, 11.9, 0.994).
Rationale: Φ\_B is a muscle-specific, literature-derived prior applied identically across subjects (not a per-subject normalization and not learned from labels). We apply Φ\_B to extracted feature vectors (not raw EMG) before channel fusion (10-channel mean) to reduce systematic inter-muscle magnitude differences and prevent large muscles from dominating the fused representation.
Muscle parameters and resulting Φ\_B weights are summarized in Supplementary Table S7.

### Classification

Random Forest (RF; scikit-learn¹¹ 1.7.1, n_estimators=200, random_state=42)³⁵ was used for LOSO evaluation. The target was 3-class assistance condition (NW, UE, PE), evaluated at the cycle×phase level (8 phases per cycle) with one 28D feature vector per cycle×phase sample. Channel-specific F18 features were first scaled by muscle-specific Φ\_B; classification input was channel-level F28 (=F18+NL10) 28D vectors aggregated across 10 channels by arithmetic mean to form one 28D vector per cycle×phase sample. For each fold, one subject was completely held out, and the remaining 9 subjects provided training data across all terrains. Cross-terrain transfer used the same LOSO design with separate train/test terrain designation. For LOSO classification and calibration experiments, we constructed a balanced evaluation dataset by randomly sampling up to 50 gait cycles per recording file (seed=42) (12,000 cycle×phase per terrain; 90 files total; before NL10 filtering).

### Calibration

0-label calibration: Terrain-specific z-score normalization using mean/std computed only from training subjects (train_only_by_terrain mode). For each feature dimension x, x' = (x − μ\_train,terrain)/σ\_train,terrain was applied, where μ and σ were estimated from training subjects only and terrain-specific statistics were selected using each sample's terrain label. This procedure requires no held-out subject labels and ensures no test-subject information leakage. Terrain labels were provided by the experimental protocol and used only to select the corresponding terrain-specific statistics.

Unlabeled subject-window adaptation (test-window calibration): For the held-out subject, we reserved the first 4 gait cycles per recording file within each test terrain as an unlabeled calibration window, computed per-(subject, terrain) z-score statistics (μ/σ) on that window, and evaluated on the remaining cycles (calibration cycles excluded from scoring). To keep the model feature scaling consistent with test-time subject-window normalization, training-subject samples were z-scored per (subject, terrain) before model fitting.

Small-label calibration: From the held-out subject's held-out-terrain test set, 10, 30, or 90 total labeled cycle×phase samples were stratified-sampled across conditions to train a multinomial logistic regression on log(RF probabilities). For numerical stability, log transform was computed as \(\log(\max(p,\varepsilon))\) with \(\varepsilon=10^{-6}\). This calibration was evaluated in a cross-terrain leave-one-terrain-out setting (train on two terrains, test on held-out terrain) under subject-independent LOSO. Evaluation used remaining samples. Repeated 30 times with different random samples to estimate variability.

### Confidence intervals

Bootstrap CIs (95%) were computed by resampling subjects with replacement (2,000 iterations) and taking the 2.5–97.5 percentile range. For each terrain cell, macro-F1 was computed per held-out subject, then aggregated as the unweighted arithmetic mean across subjects (equal subject weighting); CIs were computed on these subject-level scores.

### Permutation importance

Domain-level group permutation importance was computed under same-terrain (in-terrain) LOSO. For each terrain and held-out subject, RF was trained on remaining subjects' samples and baseline macro-F1 was computed on the held-out subject. Then for each domain (Time: f18\_01–06; Freq: f18\_07–11; Wave: f18\_12–18; NL10: nl\_*), domain feature columns were permuted independently across test-set rows (20 repetitions per domain) and macro-F1 drop was measured. 95% CIs were estimated by bootstrapping per-subject mean drops (2,000 iterations).

### Coordination metrics

For each subject, terrain, and condition, muscle-specific 28D feature vectors were concatenated across cycle×phase segments (flattened across feature dimensions) to form muscle-specific feature trajectories, then z-score transformed per muscle vector within each terrain×condition cell. Pearson r was then computed between muscle vectors to yield 10×10 inter-muscle correlation matrices. Summary metrics: mean |r| (mean_abs_r; arithmetic mean of 45 unique off-diagonal |r| values from upper triangle) and mean_r (signed arithmetic mean of same 45 r values). Network density = (pairs with |r| ≥ threshold) / 45. Normalized density AUC (edges_auc_norm) was computed by integrating density over threshold range and dividing by range width.

### Latency benchmark

End-to-end latency was measured in Python on Apple M1 for 5 cycles per terrain (15 total across three terrains). Event detection was timed once per file then divided by cycle count for per-cycle (amortized) time; per-cycle timing included preprocessing, phase segmentation (indexing), feature extraction (F18 or F28), and model inference. Setup/model training and disk I/O were excluded. Percentiles (p95/p99) were computed over the distribution of per-cycle measurements. Inference-only latency used pre-computed features for 1,000 repetitions after 5 warmup iterations. Benchmarking environment/code identifiers were recorded (macOS 26.3 arm64; Python 3.11.5; numpy 1.26.4; scipy 1.15.2; scikit-learn 1.7.1; repository commit 4e38a5b409e338c1e890bb64f86461fa4cd46926). RF inference used scikit-learn parallelism (n_jobs = −1). The reported "~9 Hz throughput" corresponds to the reciprocal of mean end-to-end latency for the F18+RF pathway (≈1/0.115 s ≈ 8.7 Hz).

### Event sensitivity

Detection parameters were varied: σ ∈ {50, 100, 150} ms, min_interval ∈ {0.4, 0.5, 0.6} s. HS/TO timing differences were computed relative to baseline (σ=100, interval=0.5). Classification sensitivity used artificial phase boundary shifts of ±10, ±20, ±40 ms with F18 feature recomputation.

### Statistical analysis

Paired t-tests with Benjamini-Hochberg correction (q < 0.05) were used for ablation analysis on subject-level (n = 10) cell metrics (paired within subject). Two-way ANOVA (condition × phase) was performed on subject-level aggregated values to avoid pseudoreplication.

### Fig. 1 | Study overview and pipeline architecture

**(a)** Data collection: 10 subjects performed walking under three assistance conditions (NW: not worn, UE: worn-inactive, PE: worn-active) across three terrains (level ground, 18° slope, stairs). **(b)** H‑MD‑WEF pipeline: 10-channel sEMG preprocessing (outlier clipping, 20–450 Hz band-pass, 60 Hz notch, rectification, Gaussian envelope; see Online Methods) → gait event detection (HS from TA, TO from GM) → HS→HS cycle segmented into 8 phases via Perry fixed percent boundaries (0–2–12–31–50–62–75–87–100%) → feature extraction: F18 (18D; time+frequency+wavelet) hierarchically fused to generate s10 (10D) for embedding/clustering, and NL10 (10D; nonlinear dynamics) computed separately for segments ≥50 samples, combined to form F28 = F18 + NL10 (10-channel mean) for RF classification. ### Extended Data Fig. 3 | Terrain-label mismatch sensitivity of 0-label calibration

### Extended Data Fig. 5 | Sampling robustness: seed × cycles-per-recording cap sensitivity

### Extended Data Fig. 6 | Missing / failure-mode handling (NL10 NaNs; wavelet sentinel=0)

NL10 nonlinear features can be undefined for short phase segments (≥50 samples requirement), producing missing values concentrated in Initial Contact. We compared three strategies without new data collection: drop-invalid samples (current), fill missing NL10 with 0, and fill 0 plus an `nl10_valid` indicator feature, reporting diagonal phase-wise macro-F1. Separately, wavelet feature summaries can return sentinel zeros for very short segments; we quantify the sentinel rate by phase×terrain and evaluate whether alternative handling (exclusion/imputation with an optional flag) changes macro-F1 (|Δ| ≤ 0.0064 across transfer cells). Reliability curves and calibration metrics for confidence estimates are provided in Source Data.

### Extended Data Fig. 7 | Leakage-safe unlabeled subject adaptation (calibration window)

We simulated an unlabeled test-time adaptation (“subject window”) by reserving the first 4 gait cycles per recording file from the held-out subject in each test terrain as a calibration window, computing per-(subject, terrain) z-score statistics (μ/σ), and evaluating macro-F1 on the remaining cycles (calibration cycles excluded). Bar plots show off-diagonal cross-terrain transfers (train terrain→test terrain) comparing baseline, 0-label train-only terrain normalization (train_only_by_terrain), and subject-window adaptation (test_window_by_terrain). Bars show subject mean macro-F1 with 95% subject-bootstrap CIs (n = 10).
