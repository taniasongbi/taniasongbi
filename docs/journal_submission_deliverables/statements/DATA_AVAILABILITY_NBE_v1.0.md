# Data availability statement (Nature Biomedical Engineering) — v1.0

## Public (processed) data

Processed feature tensors (cycle×phase 28D features), metadata, analysis tables, and benchmark results that support the findings of this study will be deposited in Zenodo upon publication (DOI to be added). Source data underlying the main and Extended Data figures and tables will be provided with the paper and/or in the Zenodo archive.

During peer review, the processed dataset and the figure/analysis source data will be made available to editors and reviewers upon request.

## Controlled-access raw data

Raw EMG recordings are not publicly available because IRB-approved informed consent limits sharing of raw signals. Raw EMG data may be made available from the corresponding author under controlled access (Data Use Agreement and institutional review as applicable) upon reasonable request.
