# Code availability statement (Nature Biomedical Engineering) — v1.0

Custom Python code used for preprocessing, feature extraction, classification, and analysis (including scripts to reproduce the figures) will be archived in Zenodo upon publication (DOI to be added). During peer review, the code will be made available to editors and reviewers upon request.

The exact version used in this study is identified by the repository commit hash reported in the manuscript, and dependency specifications are provided in the repository (for example, `requirements.txt`).
